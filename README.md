# 💊 Drug Sales Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing drug sales data using Python. The aim is to understand sales patterns, identify trends, and generate meaningful insights from the given dataset.

The project involves data loading, data cleaning, data processing, analysis, and visualization using Python.
## 🎯 Objectives
- Analyze the given drug sales dataset
- Clean and preprocess the data
- Identify important sales trends and patterns
- Analyze product-wise sales performance
- Create meaningful visualizations
- Generate useful insights from the data

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV

## 📂 Project Files

- **DrugSalesData.csv** – Dataset used for the analysis
- **drug sales data analysis.py** – Python source code
- **DRUG SALES ANALYSIS USING PYTHON documentation.docx** – Project documentation
- **DRUG SALES ANALYSIS presentation.pptx** – Project presentation

## 🔍 Project Workflow

1. Import the required Python libraries
2. Load the drug sales dataset
3. Explore and understand the dataset
4. Clean and preprocess the data
5. Perform data analysis
6. Create data visualizations
7. Identify important trends and insights
8. Present the analysis results
